# Store assets

Everything the store consoles ask for, ready to upload. Nothing here is a secret.

- `listing.md`: name, short and full description (Arabic and English).
- `icons/`: 1024 (App Store), 512 (Google Play), 216 (AppGallery).
- `feature-graphic-1024x500.png`: Google Play feature graphic.
- `screenshots/android/`: 1080×1920, for Google Play and AppGallery.
- `screenshots/iphone/`: 1290×2796, for the App Store (iPhone 6.9").
- `privacy-policy-draft.md`: draft text; the stores need it published at a public URL first.

App id on every store: `com.midtrans.syriantariff`.
